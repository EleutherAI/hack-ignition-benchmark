# Provenance of the runs published before this library

The dataset's first 308 runs (v0.1, September 2026) were made by the research code this library was extracted from,
deployed by copying a working tree onto the training machines. Where the copy was not a clean commit, the exact code
that ran cannot be named. `provenance_v01/repo_commit_attribution.jsonl` records, for each of the 308 runs, the best
attribution the surviving evidence supports:

| tier | meaning | runs |
|---|---|---|
| exact | the trainer that ran is byte-identical to the file at the named commit, and so is every other file that affects training | djinn_v2 128, backdoor 14 |
| bound | the run launched from an uncommitted working tree, between two named commits (`bound_lo`, `bound_hi`) | mbpp 120, backdoor 34 |
| archived blob | the only surviving copy of the trainer is an archived file, not any commit | backdoor 12 |

Each row's `evidence` field says how the tier was established (file hashes of the deployed trees against the commits,
and file timestamps).

Runs added to the dataset after 2026-09-14 (v0.1.1 to v0.1.6: the monitor family and the later mbpp groups) carry a
run card with a commit stamp and full rollouts. One group, `mbpp/geom_restart`, records no commit.

None of these runs is regenerated by default. Their configurations are reproduced by the recipes in `recipes/`
(generated from, and checked against, the exact trainer arguments each run recorded), and `docs/PARITY.md` reports how
closely regenerated runs match the published seeds. Whether to regenerate the non-exact runs as a new dataset version
is a separate decision.
